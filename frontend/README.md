# Blood Buddy - React Application

A modern blood donation platform built with React, Vite, and Tailwind CSS.

## 🩸 Features

- **Home Page**: Beautiful hero section with video background, about section, volunteers list, and testimonials
- **Registration**: User-friendly registration form with password strength indicator
- **Donate**: Information about how to become a blood donor
- **Get Help**: Contact form for people in need of blood
- **Responsive Design**: Fully responsive across all devices
- **Modern UI**: Built with Tailwind CSS for a beautiful, modern interface

## 🚀 Tech Stack

- **React 18** - Modern React with hooks
- **Vite** - Lightning-fast build tool
- **React Router** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework
- **Font Awesome** - Icon library

## 📦 Installation

1. Navigate to the frontend directory:
```bash
cd frontend
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit: `http://localhost:5174/`
